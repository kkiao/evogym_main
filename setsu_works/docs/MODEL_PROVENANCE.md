# 学習済みモデルの由来と収録範囲

## この文書の目的

本提出物は、主要結果の再評価に必要な選択済みモデルを収録する一方、全チェックポイント、オプティマイザ状態、監視ログ、数GB規模の中間軌跡を収録していない。本書は、各プロジェクトの初期化元、提出済みモデル、除外物、再現可能な範囲を区別する。

## 欠落物が意味する制約

選択済みモデルを読み込み、主要な評価値と代表的挙動を確認することはできる。一方、元のオプティマイザ状態、乱数生成器状態、完了済み時間ステップ、全監視ログがないため、過去の学習を同一時点から厳密に再開することはできない。

`--init-model` などを持つ学習入口では、提出モデルを初期値とする新しい学習実験を開始できる。ただし、これは元実験の厳密な断点再開ではない。平地および可動障害物の旧描画入口の一部は、提出対象外の `runs/` 構造を前提とするため、提出GIFの一括再生成入口とは数えない。

## 除外方針

GitHub提出では、結果の確認に必要な最良モデル、失敗を説明する代表モデル、設定、数値表、図、GIF、ハッシュ証拠を優先した。容量だけを増やす重複チェックポイント、仮想環境、キャッシュ、生成可能な中間ファイルは除外した。除外したモデルを、提出済みまたは完全再現可能であるかのように扱わない。
