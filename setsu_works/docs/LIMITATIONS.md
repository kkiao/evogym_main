# 制約と主張範囲

## 主張できること

- PPOにより三種類の軟体身体で平地前進を学習できた。
- 可動障害物では原始身体と層状身体がランダム行動を上回る部分的な連続越障を示した。
- 固定二壁条件では長脚身体が二壁を完全通過し、安定着地できた。
- 複数の専門方策を段階別に組み合わせると、間隔を固定した二壁課題を達成できた。
- 汎用学生の見かけ上の成功に対し、地図境界観測の因果作用を必要性と十分性の両方から確認した。

## 主張できないこと

- 任意の高さ、幅、形状、間隔の障害物を通過できるとは言えない。
- 長脚階層制御を単一の汎用ニューラルネットワークとは呼べない。
- Level 3からLevel 7までを学習済みとは言えない。
- 可動障害物実験を七組完全成功とは呼べない。
- M6L学生の旧1/11を汎化成功率として扱えない。
- 最新Level 2 v2を全軌跡完全無側倒とは呼べない。
- 一乱数種の身体比較だけから一般的な形態優位性を断定できない。
- 仮想環境の結果を実機性能として解釈できない。

## 教師利用の境界

教師は訓練用の実演、救援、データ収集に限って利用する。検証、留保、最終学生試験では教師モジュールを読み込まず、介入回数を必ず零にする。教師補助の成功数を学生の成績へ加えてはならない。
