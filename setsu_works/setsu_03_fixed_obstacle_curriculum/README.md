# 固定障害物カリキュラムと三身体比較

## プロジェクトの位置付け

可動障害物では「押して動かした結果」と「身体が壁を越えた結果」を分離しにくかった。本実験では障害物を地面と同じ静的ボクセルにし、押し退けられない固定壁を身体全体で越えられるか調べた。原始身体、層状身体、長脚身体を比較し、後続の主身体を選ぶ役割も持つ。

## 目的

- 可動物体の移動に依存しない、本当の固定壁通過を評価する。
- 単壁から複数壁、幅、高さ、密集配置へ難度を上げるカリキュラムを作る。
- 同じ厳格な最終判定で三身体を比較する。
- 学習途中の一時的突破と、その後の忘却を5kごとに検出する。

## カリキュラム設計

実装上はLevel 0からLevel 7までを定義した。

| Level | 内容 |
|---:|---|
| 0 | 平地歩行 |
| 1 | 単一低壁 |
| 2 | 間隔のある二つの低壁 |
| 3 | 細い低壁と幅広低壁 |
| 4 | 階段状障害物と高壁を追加 |
| 5 | 七組の固定混合障害物 |
| 6 | 位置14と20の密集二低壁 |
| 7 | 位置14と16の隣接二低壁 |

提出時の比較対象は最終的に二つの低壁である。原始身体と層状身体はLevel 7を直接学習した。長脚身体はLevel 6で学習し、全チェックポイントをより厳しいLevel 7へ再評価した。したがって、最終評価基準は共通だが、学習経路まで完全に同一の形態比較ではない。

## 成功条件

次のすべてを満たす場合だけ成功とした。

1. 各壁について、身体の最左点が壁後端を完全に越える。
2. 二壁通過後に前進が止まりすぎず、指定範囲の速度を保つ。
3. 上半身が地面へ倒れず、身体高さと接地条件を満たす。
4. 上記の安定状態を50ステップ連続で維持する。

重心の一部が壁を越えただけ、壁上で停止しただけ、通過直後に転倒した場合は成功に含めない。

## 学習方法

三身体ともPPOを使用した。主な設定は、学習率0.0001、ロールアウト2048、バッチ64、更新10エポック、割引率0.995、評価間隔5k、評価3エピソードである。各身体は前段の平地または単壁方策から初期化した履歴を持つが、提出物には最終比較に必要な選択済みモデルだけを収録した。

進捗報酬だけでなく、壁接近、局所的な持ち上げ、通過率、完全通過、安定終了を段階的に評価した。最大位置、通過数、評価リターン、成功率を5kごとに保存した。

## 結果

| 身体 | 選択学習時点 | Level 7通過数 | 安定成功 |
|---|---:|---:|---|
| 原始身体 | 100k | 0/2 | 失敗 |
| 層状身体 | 110k | 0/2 | 失敗 |
| 長脚身体 | 45k | 2/2 | 成功 |

長脚45k方策はLevel 7再評価で461ステップで終了し、二壁完全通過と50ステップ安定を満たした。最大到達位置は約2.314、累積リターンは約229.419であった。

一方、同じ長脚系列でも40kは0/2、45kは2/2、50kは再び0/2であった。成功技能は単調に向上せず、わずかな追加更新で消失した。

## 実現できたこと

- 押し退け不可能な固定壁に対して、長脚身体の二壁完全通過を確認した。
- 通過後の安定まで含む厳格な成功条件を実装した。
- 5k間隔の再評価により、45kの短い突破区間を発見した。
- 原始・層状身体の失敗も同一指標で保存し、身体形態の影響を比較できた。
- 長脚身体を後続の階層越障と汎用学生の主身体に選ぶ根拠を得た。

## 実現できなかったことと制約

- 原始身体と層状身体は隣接二壁を越えられなかった。
- 長脚方策も50k以降に成功を保持できず、学習の安定性は低い。
- 長脚はLevel 6学習後にLevel 7評価、他二身体はLevel 7直接学習であり、完全な統制実験ではない。
- 主な比較は乱数種7であり、形態優位性の統計的結論には追加乱数種が必要である。
- 成功は二つの低壁に限定され、高壁、幅広壁、七組混合課程への一般化は確認していない。

## 収録ファイル

- `src/`：身体、固定課程、静的環境、PPO学習、厳格評価、描画コード。
- `models/original_best_failure.zip`：原始身体の比較用失敗モデル。
- `models/layered_best_failure.zip`：層状身体の比較用失敗モデル。
- `models/long_legged_step_045000_success.zip`：長脚45k成功モデル。
- `results/comparison/`：5kごとの四指標と突破・忘却図。
- `results/*/course.json`：各身体が使用した正確な課程。
- `media/`：長脚40k、45k、50kの比較GIF。

## 再評価

```powershell
$env:PYTHONPATH = (Get-Location).Path
python -m src.diagnose_policy --body-name long_legged --level 7 models\long_legged_step_045000_success.zip
```

この結果は固定された隣接二低壁だけの成果であり、任意障害物の汎用成功とは表現しない。
