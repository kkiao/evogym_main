# 平地移動強化学習実験

## プロジェクトの位置付け

本実験は全研究の出発点である。障害物を導入する前に、軟体ロボットがPPOで前進運動を獲得できることを確認し、後続の転移学習に使用できる基礎方策を作成した。同時に、原始身体と層状身体で観測・動作次元と移動性能がどのように変わるかを比較した。

## 目的と仮説

- 原始身体がWalker平地環境で安定した正方向移動を学習できるか確認する。
- 材料とアクチュエータを層状に増やした身体が、より大きな前進速度を獲得できるか調べる。
- 学習済み方策、ランダム行動、未学習方策を同一条件で評価し、報酬増加が実際の前進に対応するか確認する。
- 原始身体について複数乱数種を実行し、単一学習の偶然性を確認する。

## 身体と入出力

| 身体 | 観測次元 | 動作次元 | 特徴 |
|---|---:|---:|---|
| 原始身体 | 42 | 4 | 小型Walkerの基準身体 |
| 層状身体 | 50 | 10 | 黒、橙、青の材料を層状に配置し、動作自由度を増加 |

動作は `-1` から `1` に正規化し、EvoGymのアクチュエータ伸縮へ変換した。各エピソードは最大500ステップである。

## 実験方法

Stable-Baselines3のPPOを使用した。主要設定は両身体で共通である。

| 項目 | 設定 |
|---|---:|
| 学習率 | 0.00025 |
| 一回のロールアウト | 2048ステップ |
| バッチサイズ | 64 |
| 更新エポック | 10 |
| 割引率 | 0.99 |
| GAE係数 | 0.95 |
| クリップ幅 | 0.2 |
| 目標学習量 | 300kステップ |
| 評価間隔 | 25kステップ |
| 一回の評価 | 5エピソード |

原始身体では乱数種7、17、27を100kまで比較した。その後、乱数種7を300kまで継続し、25kごとの評価で最良チェックポイントを選択した。層状身体は乱数種7を300kまで学習した。提出モデルは最終重みではなく、決定論的評価リターンが最も高かった重みである。

## 評価方法

評価では次を記録した。

- エピソード累積リターン
- 500ステップの前進距離と平均速度
- ランダム行動との差
- 原始身体三乱数種の平均、標準偏差、最小値、最大値

教師や外部制御器は使用していない。保存済みPPO方策だけで評価する。

## 結果

| 身体・条件 | 学習時点 | 評価リターン | 平均速度 |
|---|---:|---:|---:|
| 原始身体・乱数種7最良 | 275k | 3.5073 | 0.00701459 |
| 層状身体・乱数種7 | 300k | 5.2965 | 0.01059308 |
| 原始身体・三乱数種平均 | 100k | 2.9865 | 0.00597309 |

原始身体三乱数種の100kリターン標準偏差は0.0851で、範囲は2.8796から3.0879であった。少なくとも原始身体の基礎歩行は一つの乱数種だけに依存しないことを確認した。

## 実現できたこと

- 二身体でランダム行動を明確に上回る前進方策を作成した。
- 原始身体では三乱数種による再現性を確認した。
- 学習曲線、設定、身体配列、最良モデル、GIFを同じ実験単位で保存した。
- 後続の可動・固定障害物実験へ移行するための基礎運動を得た。

## 実現できなかったことと制約

- 層状身体は主に一乱数種であり、一般的に原始身体より優れるとは断定できない。
- 身体ごとに観測・動作次元が異なるため、速度差には形態だけでなく方策容量の差も含まれる。
- 平地で速い方策が障害物でも強いとは限らない。実際、後続実験では層状身体が常に優位ではなかった。
- 本実験は前進を対象とし、旋回、外乱耐性、任意方向移動は評価していない。

## 収録ファイル

- `src/`：身体定義、PPO学習、ランダム基準、評価、描画コード。
- `models/original_best.zip`：原始身体の最良方策。
- `models/layered_best.zip`：層状身体の最良方策。
- `results/original/`、`results/layered/`：設定、評価表、学習曲線、身体配列。
- `results/multiseed/`：原始身体三乱数種の比較。
- `media/`：二身体の代表GIF。

## 再評価

```powershell
$env:PYTHONPATH = (Get-Location).Path
python -m src.evaluate_submission --body original --episodes 20
python -m src.evaluate_submission --body layered --episodes 20
```

評価出力には `teacher_module_loaded: false` と `teacher_interventions: 0` を記録する。
