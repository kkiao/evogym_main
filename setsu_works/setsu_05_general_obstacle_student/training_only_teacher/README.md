# 訓練専用教師

このディレクトリは訓練中の実演と救援に使う教師目録を隔離するための領域である。検証、留保、最終学生試験では教師を完全に停止する。

`teacher_manifest.json` は九つの既知引継ぎ経路と二つの未対応位置を記録する。提出物には教師の全学習履歴と大量の中間重みを含めていない。長脚制御モデルは兄弟ディレクトリ `setsu_04_long_legged_hierarchical` に保存されているが、汎用学生の最終評価入口からは参照しない。

禁止事項は次の通りである。

- 検証集合で教師を動作させること。
- 留保集合で教師を動作させること。
- 最終学生試験で教師を読み込むこと。
- 教師補助成功を学生成功として集計すること。
