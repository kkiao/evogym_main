# 汎用障害物学生の学習試行と境界依存の因果診断

## プロジェクトの位置付け

長脚階層制御では固定二壁を攻略できたが、十個の専門方策と手作業の状態機械を必要とした。本実験の目標は、それらの実演・救援素材と強化学習を用いて、一つの学生ニューラルネットワークが異なる開始位置や障害物配置を局所観測だけから処理できるようにすることであった。

最終的に汎用成功モデルは得られなかった。しかし、学生が地図外観測を動作切替の近道として利用したことを、物理地図と観測符号化を独立に操作する因果実験で確認した。本プロジェクトは、強化学習における報酬・観測漏洩、教師分布と学生分布のずれ、見かけ上の成功を厳格に検証する負の結果として整理する。

## 研究目標

- 長脚身体の複数越障技能を一つの学生方策へ統合する。
- 障害物の絶対位置、課程番号、現在段階を学生へ直接与えず、局所観測だけで行動させる。
- 訓練、検証、留保の乱数種と地形分布を分離する。
- 教師は訓練実演と救援に限定し、最終学生試験では完全に停止する。
- 成功だけでなく、硬い転倒、停止、教師接管、着地、再前進を記録する。
- 学習が停滞した場合、教師追加だけでなく逆カリキュラム、密な開始状態、接触蒸留、PPOを比較する。

## 身体、動作、観測

学生は長脚身体を使用し、動作次元は6である。観測は95次元で、次の情報を含む。

- 重心の水平・垂直速度
- 初期直立姿勢に対する角度の正弦・余弦
- 角速度
- 身体各点の相対位置
- 後方5、前方30ボクセルの相対地表走査
- 直前の6次元動作

絶対位置、課程ID、乱数種、難度、障害物番号、現在の制御段階、終点位置は特権情報として観測から除外した。一方、地図範囲外の走査値を固定値 `0.5` で埋めたため、後にこの固定値が実質的な境界標識になることが判明した。

## ランダム課程と分割

固定された一枚の地図だけでなく、乱数種から障害物種類、開始滑走距離、間隔を生成する課程を用意した。訓練、検証、留保を別の分割として扱い、訓練中に検証・留保へ教師を持ち込まない規約を凍結JSONとして保存した。

成功判定では、障害物の生の通過だけでなく、通過後の安定回復と再前進を要求した。上半身接地、角度、角速度、停止時間、局所通過率も監査した。

## 使用した方法と開発段階

### M1：環境、身体、受入判定

手続き型地形、長脚身体、局所観測、訓練・検証・留保分割、幾何可行性検査、成功・転倒・停止判定を実装した。ここで「学生が利用できる情報」と「評価器だけが利用する情報」を分離した。

### M2：教師実演と対話的救援

長脚の専門方策を接近、通過、着地、再前進として組み合わせ、学生が危険状態へ入った場合だけ教師へ接管する対話的救援を試した。さらに次を実装した。

- 学生プレフィックス後の救援開始状態の保存
- 成功した教師軌跡の監査と完全再生
- 段階均衡型の行動クローニング
- 閉ループ補正と摂動回復
- 位置別の教師経路探索と目録化

教師はすべての状態を救えるわけではなく、特に学生が一歩でも教師の制御可能領域から外れた後は救援成功率が急低下した。位置21と22は初期の教師経路でも未被覆であった。

### M3：再帰型学生と層別模倣

LSTMを持つ学生を使用し、平地プレフィックス、障害物接近、教師救援窓、回復後の四層を均等に学習する層別模倣を試した。教師の行動を単純に大量複製するのではなく、各段階が損失へ同じ比重で入るようにした。批評器を固定し、主に行動側の層を更新する安全な初期化探索も行った。

### M4・M4R：学習器誘導状態での教師救援復核

学生重みを更新せず、学生自身が到達した状態から教師が本当に回復できるか検査した。M4Rでは開始姿勢、教師行動との差、接管時刻、救援経路を探索し、訓練専用の事前行動安全シールドまで試した。

この段階で、教師は既知の初期状態では強くても、学生が作る分布外状態の回復器としては弱いことが明確になった。教師をさらに細分化して増やすだけでは専門モデルが増え続け、単一学生の問題を解決しないと判断した。

### M5：逆カリキュラムPPO

最初から完全な越障を要求せず、成功に近い状態から逆向きに開始位置を戻した。

1. 安定終了
2. 通過後回復
3. 壁接触変形
4. 壁直前
5. 完全な開始位置

8個のCPU並列環境を用い、12,288ステップごとにチェックポイントを評価した。学生へ制御を渡した後の教師行動は零とした。この方法で局所段階の学習は進んだが、完全開始からの一貫した成功には接続できなかった。

### M6系列：接続区間の強化

M5後の主要問題を「個別動作の欠如」より「技能間の接続」と見なし、次を試した。

| 段階 | 方法 | 狙い |
|---|---|---|
| M6 | 密なハンドオフ課程 | 教師終了と学生開始の間を0.1刻みの開始率で埋める |
| M6R | 接触区間の行動蒸留とオンラインPPO | 壁変形直前の狭い帯域を重点学習する |
| M6L | 学習器だけの着地課程 | 教師なしで通過後の着地・回復を強化する |
| M6S | 成功・安全アンカー | 失敗前着地を学びながら既存成功と平地歩行を保持する |

最良として残ったM6L学生は位置20で一回の回復を示したが、11位置全体では1/11にすぎず、M6Sでも汎用成功条件を満たさなかった。

### 最終段階：二要因の境界因果検証

位置20の成功が本当に障害物技能か調べるため、第一壁を同一に保ち、次の二因子だけを独立に変更した。

1. 物理地図を短くするか長くするか。
2. 仮想境界以後の観測を地図外固定値にするか平地表現にするか。

## 因果検証結果

| 物理地図 | 境界以後の観測 | 第一壁後の回復 | コース完了 |
|---|---|---|---|
| 短地図 | 地図外固定値 | 成功 | 失敗 |
| 短地図 | 平地表現 | 失敗、壁前停止 | 失敗 |
| 長地図 | 平地表現 | 失敗、壁前停止 | 失敗 |
| 長地図 | 地図外固定値 | 成功 | 失敗 |

同じ観測符号化を与えた短地図と長地図では、観測95要素と動作6要素が全ステップで完全一致した。固定値を平地表現へ変えた最初のステップ287で動作も分岐した。

したがって、地図外固定値は成功に必要であり、長い物理地図へ人工的に追加すると成功を再現するため十分でもある。物理地図長そのものではなく、境界観測が動作切替の原因である。

## 最終結論

M6Lモデルは一般的な越障技能を獲得したのではなく、「特定位置で前方走査に現れる地図外固定値」を越障・回復動作の合図として利用した。強化学習では、このように目的と相関する簡単な観測特徴があると、本来学んでほしい因果構造より近道を選ぶことがある。

旧1/11を汎化成功率として報告してはならない。このモデルは汎用成功モデルではなく、観測表現漏洩と方策近道を示す診断対象モデルである。

## 実現できたこと

- 手続き型ランダム地形と訓練・検証・留保分割を実装した。
- 95次元局所観測、6次元動作、再帰型学生の学習基盤を作成した。
- 模倣、対話的救援、層別学習、逆カリキュラム、密なハンドオフ、蒸留、PPOを比較した。
- 学生分布上で教師の実際の救援限界を重み更新なしで検証した。
- 教師を訓練専用に隔離し、学生だけの評価入口と自動試験を整備した。
- 見かけ上の成功原因を必要性・十分性の両方向から因果的に特定した。

## 実現できなかったこと

- 一つの学生で11開始位置を安定して成功させられなかった。
- 位置21、22を含む教師救援範囲を完全に構築できなかった。
- 学生が教師制御領域を外れた後の一般回復器を作れなかった。
- 単壁技能を複数障害物、未知高さ、未知間隔へ一般化できなかった。
- 平地歩行、壁接触、通過、着地、安全性を一つの重み集合で同時に保持できなかった。
- 最終M6L・M6S系列を汎用成功モデルとして採用できなかった。

## 教師の使用制約

- `training_only_teacher/` は訓練用目録と必要最小限の教師証拠だけを収録する。
- 教師は訓練実演、訓練救援、訓練データ収集だけに使用する。
- 検証、留保、最終学生試験では教師を読み込まない。
- `student_only_evaluation.py` は教師引数を持たない。
- 最終評価では `teacher_module_loaded: false`、`teacher_interventions: 0` を要求する。
- 教師補助結果を学生成績として報告しない。

## 再利用できるものとできないもの

再利用できるものは、身体・地形生成、成功判定、観測スキーマ、分割、試験、逆カリキュラム、因果介入、教師隔離の設計である。専門方策は訓練実演として利用できる。

そのまま汎用成功として再利用できないものは、M6L最良重み、位置20の旧1/11、地図外固定値を含む成功評価である。M6L重みは失敗原因を再現する診断素材としてのみ残す。

- `models/m6l_best_student_boundary_dependent.zip`：境界依存の診断対象学生。
- `results/boundary_causal_validation/summary.json`：四条件の数値と軌跡比較。

## 自動試験

兄弟ディレクトリの長脚コードも検索パスに追加する。

```powershell
$longLegPath = (Resolve-Path ..\setsu_04_long_legged_hierarchical).Path
$env:PYTHONPATH = "$(Get-Location);$longLegPath"
python -m pytest -q
```

`tests/conftest.py` は、提出物から除外した数GB規模の中間軌跡と旧チェックポイントを必要とする履歴試験だけを収集対象外にする。試験ソースと旧プロトコルは研究経緯として残すが、単独再実行可能な最終試験数へは含めない。
