# 長脚ロボットの階層越障制御

## プロジェクトの位置付け

固定二壁実験では長脚身体だけが突破したが、単一PPOの成功は45k付近に限られ、追加学習で失われた。本実験では、越障を一つの長い行動として学習させるのではなく、接近、部分通過、完全通過、着地、再前進へ分解し、専門方策を状態機械で切り替える方法を採用した。

この成果は後続の汎用学生に対する訓練実演・教師素材の一部となる。ただし、専門方策の組合せ自体を汎用学生の最終成績には使用しない。

## 目的

- 長脚身体で平地、単壁、二壁を段階的に達成する。
- 壁を越えるだけでなく、安定着地と再前進を明示的に評価する。
- 単一PPOが苦手とする長い時間依存課題を、複数の短い制御区間へ分割する。
- 方策切替条件とモデル対応を目録化し、複数モデル制御を再現可能にする。
- 姿勢と上半身接地を記録し、見た目だけの成功を避ける。

## 身体と課程

長脚身体は幅5ボクセル、6個のアクチュエータを持つ。局所地形を観測し、Level 0では平地歩行を学習した。障害物間の空地は三身体幅、すなわち15ボクセルに固定した。

全体設計ではLevel 0からLevel 7を用意した。

| Level | 設計内容 | 本提出での状態 |
|---:|---|---|
| 0 | 平地歩行と再前進 | 完了 |
| 1 | 単一低壁 | 完了 |
| 2 | 三身体幅離れた二低壁 | 完了 |
| 3 | 三つの低壁 | 未学習 |
| 4 | 低い幅広壁を追加 | 未学習 |
| 5 | 高い細壁を追加 | 未学習 |
| 6 | 階段状障害物を追加 | 未学習 |
| 7 | 七組の固定混合障害物 | 未学習 |

レベル定義が存在することと、学習済みであることを区別する。

## 方法

### Level 0

PPOにより平地移動と再前進を学習した。主な設定は、学習率0.0001、ロールアウト2048、バッチ64、更新10エポック、割引率0.995、ネットワーク幅128、評価間隔5k、最大900ステップである。選択済みモデルは `models/flat_level0_best.zip` に保存した。

### Level 1とLevel 2

壁に対する一連の運動を、次の制御区間に分けた。

1. 壁へ接近する。
2. 身体の一定割合を壁後方へ送る。
3. 身体全体を壁後端より先へ送る。
4. 速度と姿勢を抑えて着地する。
5. 着地後に再び一身体幅以上前進する。

Level 2 v2では十個のPPO方策を使用する。

| 順番 | 方策 | 役割 |
|---:|---|---|
| 1 | `approach` | 第一壁への接近 |
| 2 | `first_to_50` | 第一壁の部分通過 |
| 3 | `first_safe_to_full` | 第一壁の安全な完全通過 |
| 4 | `first_landing` | 第一壁後の着地 |
| 5 | `first_restart` | 第二壁へ向けた再前進 |
| 6 | `second_to_33` | 第二壁の初期通過 |
| 7 | `second_to_50` | 第二壁の中間通過 |
| 8 | `second_to_full` | 第二壁の完全通過 |
| 9 | `second_landing` | 第二壁後の着地 |
| 10 | `second_restart` | 最終再前進 |

状態機械は障害物に対する身体の通過率、姿勢、速度、接地、安定時間を監視して方策を切り替える。単に一定時刻で切り替える方式ではない。モデルの相対パスと評価値は `policies/level2_true_no_side_fall_v2.json` に固定した。

## 厳格評価

各障害物について次の三事象を別々に数えた。

- 身体全体の完全通過
- 通過後の安定着地
- 着地後の一身体幅以上の再前進

さらに、初期直立姿勢からの最大角度誤差と、上半身が地面近傍にあったステップ数を各制御区間で記録した。

## 結果

| 課程 | 完全通過 | 安定着地 | 再前進 | 結果 |
|---|---:|---:|---:|---|
| Level 0 平地 | 対象外 | 対象外 | 成功 | 完了 |
| Level 1 単壁 | 1/1 | 1/1 | 1/1 | 成功 |
| Level 2 二壁 | 2/2 | 2/2 | 2/2 | 成功 |

Level 2 v2は980ステップで終了し、厳格通過2、着地2、再前進2を達成した。最適化対象の後半八区間では最大姿勢誤差28.69度、上半身近地0ステップであった。

ただし、旧方策を使う最初の接近・部分通過区間まで含めると、全軌跡の最大姿勢誤差は70.41度、上半身近地は82ステップである。したがって、全行程完全無側倒は偽であり、「最適化した制御区間では無側倒の二壁成功」と表現する。

## 実現できたこと

- 単一PPOでは不安定だった二壁課題を、専門方策と状態機械で完了した。
- 通過後の着地と再前進までを明示的に達成した。
- 十個のモデル、切替順序、評価値を相対パスで再構成できるようにした。
- 区間別の姿勢・接地監査により、成功のどの部分が安全かを分離した。
- 汎用学生の訓練実演に利用できる具体的な動作素材を得た。

## 実現できなかったことと制約

- Level 3からLevel 7は未学習である。
- Level 2は一つのニューラルネットワークではなく、十個の専門方策の組合せである。
- 障害物の高さ、幅、間隔は固定で、未知配置への一般化は確認していない。
- 全軌跡完全無側倒ではない。
- 状態機械は障害物進捗に関する内部判定を使用し、局所観測だけの単一学生より多くの設計知識を持つ。
- 専門方策を増やし続ける方法だけでは任意障害物へ拡張しにくく、最終的には単一学生の強化学習・模倣学習が必要となる。

## 収録ファイル

- `ll7/`：身体、課程、環境、PPO学習、診断、状態機械、厳格評価コード。
- `models/flat_level0_best.zip`：平地方策。
- `models/` 内の十モデル：Level 2 v2制御チェーン。
- `policies/level2_true_no_side_fall_v2.json`：モデル対応と評価目録。
- `results/level0/`：平地設定と学習結果。
- `results/level2_v2/`：進捗、姿勢、接地監査図。
- `media/`：平地、単壁、二壁の代表GIF。

