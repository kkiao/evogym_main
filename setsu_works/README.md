# EvoGym軟体ロボット強化学習プロジェクト

## この文書の役割

本書は、原始身体の平地歩行から始まり、身体形態の比較、可動・固定障害物、長脚ロボットの階層制御、単一の汎用学生方策、最後の因果検証までを一つの研究過程として説明する総合案内である。各ディレクトリのREADMEには、その実験だけの設計、実装方法、成功、失敗、再評価方法を詳しく記載した。

チームリポジトリ上の個人提出ディレクトリ名は `setsu_works` である。その直下に、実験順を示す `setsu_01` から `setsu_05` までの五プロジェクトを配置する。

本提出物は「すべての障害物を解決した完成モデル」ではない。強化学習で獲得できた能力、身体形態によって変化した学習可能性、複数方策を組み合わせた場合の到達点、単一学生への統合が失敗した原因を、成功例と負の結果の両方から示すものである。

## 研究目的

主要な問いは次の四点である。

1. 軟体ロボットはPPOにより安定した前進運動を獲得できるか。
2. 身体構造を変えると、平地速度と固定障害物の通過可能性はどう変わるか。
3. 一つの方策で難しい越障を、専門方策と状態機械に分解すると実現できるか。
4. 分解した専門技能を一つの学生ニューラルネットワークへ統合し、未知位置へ一般化できるか。

最初の三点では明確な成果が得られた。四点目では見かけ上の成功が得られたものの、厳格な因果検証により地図境界観測を利用した近道であると判明した。

## 使用した三種類の身体

| 身体 | 主な特徴 | 主な用途 |
|---|---|---|
| 原始身体 | 4動作の小型Walker | 基礎歩行、可動障害物、固定壁比較の基準 |
| 層状身体 | 10動作、複数材料を層状に配置 | 動作自由度を増やした場合の速度と越障比較 |
| 長脚身体 | 6動作、地上高を大きくした脚部 | 固定壁、階層越障、汎用学生の共通身体 |

身体を変更すると観測次元、動作次元、接触様式が変わるため、方策重みは基本的にそのまま流用できない。一方、環境設計、成功判定、評価コード、因果検証方法は身体が変わっても再利用できる。

## 実験全体の流れ

| 段階 | 実験 | 方法 | 得られた結論 | 次段階への判断 |
|---|---|---|---|---|
| 1 | 平地移動 | 原始身体と層状身体をPPOで学習 | 両身体で前進を獲得し、層状身体が単一乱数種では高速 | 平地方策を後続課題の初期化材料とする |
| 2 | 七組の可動障害物 | 平地由来方策を転移し、地形観測付きPPOを継続 | 原始身体3/7、層状身体2/7、全経路成功0% | 可動物体を押せる曖昧さを除き、固定壁へ移行 |
| 3 | 固定二壁と身体比較 | 地面一体型の静的壁、厳格通過・安定判定 | 原始・層状0/2、長脚2/2 | 長脚身体を越障の主身体として採用 |
| 4 | 長脚階層制御 | 接近、通過、着地、再前進を専門PPOへ分割し状態機械で切替 | 単壁1/1/1、二壁2/2/2を達成 | 専門技能を訓練教師・実演材料として利用 |
| 5 | 汎用学生 | ランダム課程、LSTM学生、模倣、救援、逆カリキュラム、PPO | 一部状態でのみ成功し、教師の救援範囲にも限界 | 学生だけの厳格評価と因果介入を実施 |
| 6 | 境界因果検証 | 物理地図長と地図外観測を独立操作する二要因実験 | 成功の原因は越障一般技能ではなく地図外固定値 | 汎用成功の主張を撤回し、負の結果として整理 |

## 共通する実験方針

### 強化学習

主な学習器はStable-Baselines3系のPPOである。連続動作を正規化し、一定間隔で決定論的評価を行い、最終チェックポイントではなく評価上の最良チェックポイントを保存した。汎用学生では時間依存の動作切替を扱うため、LSTMを持つ再帰型方策も使用した。

### カリキュラムと分解

課題を平地、単壁、二壁、複合障害物へ段階化した。単一報酬だけで学習が進まない場合は、障害物接近、部分通過、完全通過、安定着地、再前進を別の状態・方策として扱った。後半の汎用学生では、ゴール側の安定状態から逆向きに開始位置を戻す逆カリキュラムと、切替区間を細かくする密なハンドオフ課程を試した。

### 成功判定

単に重心が前へ出たことを成功としない。固定障害物では身体全体の後端通過、着地後の速度、姿勢、接地、一定時間の安定を確認した。長脚階層制御では、各障害物について完全通過、安定着地、身体一幅以上の再前進を別々に記録した。

### 教師利用の境界

教師は訓練中の実演、救援、データ収集にだけ使用する。検証、留保、最終学生試験では教師を完全に停止する。最終学生評価は教師モジュール読込なし、教師介入回数零で実行し、教師が操作した成功を学生成績へ加えない。長脚階層制御そのものも、汎用学生の最終評価では使用しない。

### 性能測定

GPUとCPU・並列環境の基準測定も行った。ニューラルネットワーク部分はGPUを利用できるが、EvoGymの物理シミュレーションと環境ステップが主な律速であり、小規模評価ではCPU実行が安定していた。そのため提出モデルの標準再評価はCPUとした。

## 主要結果

| 実験 | 結果 |
|---|---|
| 原始身体の平地移動 | 275kでリターン3.5073、平均速度0.00701459 |
| 層状身体の平地移動 | 300kでリターン5.2965、平均速度0.01059308 |
| 原始身体の三乱数種100k | 平均リターン2.9865、標準偏差0.0851 |
| 可動障害物 | 原始身体3/7、層状身体2/7、両者とも全経路成功率0% |
| 固定二壁 | 原始身体0/2、層状身体0/2、長脚身体2/2 |
| 長脚階層制御 | 二壁の通過、着地、再前進を2/2/2で達成 |
| 汎用学生 | 旧評価1/11は地図境界観測に依存し、汎化成功ではない |

## 実現できたこと

- 三種類の身体について、強化学習による平地前進の基盤を作成した。
- 可動障害物でランダム行動を上回る部分的な連続進行を確認した。
- 静的二壁に対し、長脚身体の厳格な完全通過と安定を確認した。
- 難しい越障を複数の専門方策へ分解し、状態機械で組み合わせる実装を作成した。
- 学生・教師・訓練・検証・留保を分離するプロトコルと自動試験を整備した。
- 見かけ上の成功に対して必要性と十分性を調べる双方向の因果検証を実施した。

## 実現できなかったこと

- 七組の可動または固定混合障害物を一つの方策で完全攻略していない。
- 長脚カリキュラムのLevel 3からLevel 7は学習済みではない。
- 十個の専門方策を一つの汎用ニューラルネットワークへ統合できていない。
- 未知の高さ、幅、形状、間隔へ一般化する学生モデルは得られていない。
- 身体比較の一部は一乱数種かつ異なる初期化経路であり、一般的な形態優位性までは断定できない。
- シミュレーション結果を実機性能として解釈することはできない。

## 提出物の構成

- `models/`：再評価または診断に必要な選択済みモデル。
- `results/`：設定、評価表、要約JSON、学習曲線、比較図。
- `media/`：結果を視覚確認する代表GIF。
- `training_only_teacher/`：訓練専用教師を隔離した領域。
- `evidence/`：提出物内のハッシュ検査に必要な最小限の凍結証拠。
- `requirements/`：用途別の依存関係。
- `docs/`：横断結果、制約、モデル由来、実試験出力、検査、出典、提出確認表。

仮想環境、実行環境、キャッシュ、全学習チェックポイント、数GB規模の中間軌跡は含めない。旧研究段階の一部プロトコルと試験は研究経緯として残すが、未収録の中間証拠を必要とするものは単独再実行対象に数えない。

## 実行環境

- Python 3.10
- EvoGym 2.0.0
- Gymnasium 1.3.0
- Stable-Baselines3 2.9.0
- PyTorch 2.13.0

PowerShellで本ディレクトリを開き、仮想環境を作成する。

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\requirements\general_student.txt
```

平地方策を再評価する。

```powershell
Set-Location .\setsu_01_flat_locomotion
$env:PYTHONPATH = (Get-Location).Path
..\.venv\Scripts\python.exe -m src.evaluate_submission --body original --episodes 3
```

長脚二壁制御を再評価する。

```powershell
Set-Location ..\setsu_04_long_legged_hierarchical
$env:PYTHONPATH = (Get-Location).Path
..\.venv\Scripts\python.exe -m ll7.final_true_noroll_v2 --output .\results\level2_v2\recheck.json
```

汎用学生プロジェクトの独立試験を実行する。

```powershell
Set-Location ..\setsu_05_general_obstacle_student
$longLegPath = (Resolve-Path ..\setsu_04_long_legged_hierarchical).Path
$env:PYTHONPATH = "$(Get-Location);$longLegPath"
..\.venv\Scripts\python.exe -m pytest -q
```
